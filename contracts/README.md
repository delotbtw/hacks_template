# Контракты

`openapi.json` — единственный источник правды для фронта и бэка. Он выгружается из FastAPI и коммитится.

## Как менять контракт

1. Поменяйте схемы/роутеры в `app/`.
2. `make contracts` — перевыгрузить `contracts/openapi.json` (детерминированно, ключи отсортированы).
3. `make front-gen` — перегенерировать типы фронта (`web/src/api/schema.d.ts`, тоже коммитится).
4. Закоммитьте `openapi.json` и `schema.d.ts` вместе с изменением кода.

## Расхождение

`tests/test_contract.py` падает, если `openapi.json` не совпадает с кодом. Это значит, что контракт
устарел: выполните `make contracts` и закоммитьте. Если расхождение возникло из-за чужой правки —
согласуйте с автором и берите его версию кода, затем перегенерируйте.

## Фронт без бэкенда

`make mock` поднимает Prism на `http://localhost:4010` по этому файлу. Запуск фронта против мока:
`cd web && VITE_API_URL=http://localhost:4010 pnpm dev`.
